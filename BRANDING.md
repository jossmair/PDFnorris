# Identité PDFnorris

- Nom public : **PDFnorris** (PDF blanc, norris orange).
- Slogan : **Aucun PDF ne lui résiste.**
- Signature : Un logiciel de la suite Ergonatus.
- Couleurs : anthracite `#171c24`, blanc `#ffffff`, orange `#ff6c00`.
- Première version publique : **V1.00**, tag GitHub `v1.00`.
- Version technique Cargo/Windows : `1.0.0`.

Le nom et le slogan de l’interface sont définis dans `src/lib.rs`.
Les anciens marqueurs PDF et le dossier de récupération sont conservés pour
ouvrir les documents et brouillons créés avec PDFinator.
Les licences et les attributions des composants restent inchangées.
